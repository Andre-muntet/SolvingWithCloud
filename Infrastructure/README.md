Purpose

This repository is designed to help beginners and anyone refreshing their AWS knowledge by learning through practical cloud engineering projects.

Rather than separating theory from implementation, each project introduces the AWS concepts it uses, explains why those services were chosen, and demonstrates how they work together to solve a real engineering problem. Infrastructure is provisioned using Terraform, reflecting modern Infrastructure as Code practices.

A dedicated terraform-notes section is included to provide references and learning resources for Terraform concepts used throughout the projects.


Start with any project that matches your current level or area of interest. Each project introduces the required AWS concepts, explains the engineering decisions behind the architecture, and provides a complete Terraform implementation. For readers who are new to Terraform, the terraform-notes section can be used as a companion reference while working through the projects.
